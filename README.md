# AI From Scratch

Implementing Machine Learning and Deep Learning algorithms completely from scratch using only NumPy.

## Goals

- Understand every mathematical concept
- Implement every algorithm manually
- Avoid using scikit-learn for implementation
- Build intuition before using frameworks

## Roadmap

- [x] Linear Regression
- [ ] Logistic Regression
- [ ] Neural Networks
- [ ] Backpropagation
- [ ] CNN
- [ ] RNN
- [ ] Transformers

## Technologies

- Python
- NumPy
- Matplotlib
- Jupyter Notebook
